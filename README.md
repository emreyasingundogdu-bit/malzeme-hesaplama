# Malzeme Hesaplama — motor yayın deposu

Bu depo ELLE DÜZENLENMEZ — `sac-plaka-hesap` (özel) deposundaki
CI tarafından her derlemede otomatik üretilir. STEP → Malzeme
Listesi programı (.exe) açılışta buradan güncelleniyor.

Buradaki `.pyc` dosyaları DERLENMİŞ bytecode. Kaynak kodun kendisi
burada değil, özel `sac-plaka-hesap` deposunda.
